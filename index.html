2. Full Methodology

Phase 0 — Preparation

5. Troubleshooting

  • Kerberos fails: fix DNS and use FQDN, not IP.
  • Hashcat rockyou missing: search with find / -name rockyou.txt* 2>/dev/null.
  • nxc -k fails: use --use-kcache and target FQDN.
  • lsassy blocked: try another host where you have admin rights.
  • No admin found: return to BloodHound, descriptions, Kerberos, SYSVOL, and spraying.
